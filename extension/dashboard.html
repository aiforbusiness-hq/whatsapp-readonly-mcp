                  怎么防恶意文件检查什么 · 检查不到什么
                  • 看文件真正的内容，不信名字。只存看得完、查得完的文件：照片、影片、声音、纯文字、PDF、新版 Office（docx / xlsx / pptx）。
                  • 其他一律不存：程序和脚本、网页、所有压缩档（zip、rar、7z）、旧版 Office（doc / xls / ppt）、RTF、SVG、名字跟内容对不上的文件。要的话，确认是认识的人传的，再自己在 WhatsApp 里下载。
                  • PDF 会解开每一部分检查：带程序码、会叫电脑执行程序、夹带别的文件，就不存。Office 文件带巨集、内嵌物件、DDE 或连到外面的范本，也不存。CSV 表格里有公式或指令（= + - @ 开头），也不存。加密、太大或太复杂看不完的，也不存。
                  • 没有「打开」按钮，只有「在文件夹中显示」。打开前先确认是认识的人传的。
                  • 检查不到：照片、影片、PDF 阅读程序本身的漏洞，和新的病毒。电脑和 Chrome 的防毒还是要开着。
