# Security policy

This project reads your own WhatsApp Web on your computer and never sends a message by itself. We take reports about it seriously.

## Report a problem

Please **do not** open a public issue for a security problem. Instead, use GitHub's private report: open the repository's **Security** tab and choose **Report a vulnerability**.

Tell us what you found, how to reproduce it, and which version you used (shown in `chrome://extensions` and in the plugin's `get_status`). We will reply as soon as we can and credit you in the release notes if you want.

## What counts

Anything that could let something other than the paired AI app on your own computer read your chats, save drafts, or send, delete or change anything in WhatsApp. For example: a way around the pairing, a web page reaching the local server, a send or mark-as-read path, an outside network request, or a downloaded file getting past the safety check.

## Supported versions

Only the latest release gets fixes. Update to it before reporting.
