# AI for Business Chat Assistant 安装说明（学员版）

让 **Claude** 或 **ChatGPT** 帮你看 WhatsApp：谁在等你回、某个群讲了什么，还能帮你起草回复。

- **不会替你发信息。** 程序里没有「发送」功能，回复永远由你自己按发送。
- **资料只在你的电脑。** 不经过任何服务器，不用注册账号。（AI 读到的内容会送去 Claude / ChatGPT 理解，跟你把对话贴进聊天一样。）
- Mac 和 Windows 都可以用。约 15 分钟装好。

> **请先读：** 这是非官方工具，跟 WhatsApp / Meta 没有关系，也没有得到他们的认可；用的是 WhatsApp Web 内部的读法。WhatsApp 有可能限制账号（只读能降低风险，但不保证）。**建议先用工作副号试。** WhatsApp 改版时可能暂时读不到，要等更新。

## 你需要

1. 电脑上的 **Google Chrome**
2. 在 Chrome 打开 **web.whatsapp.com** 并扫码登入
3. 以下 AI 其中一个：
   - **Claude 桌面版**（最简单，推荐）
   - **ChatGPT 桌面版**（Codex / Work，要先装 Node.js，见第 3B 步）
   - **Claude Code**（会用终端机的人）
4. 老师给你的压缩档 `AIforBusiness-Chat-Assistant-v版本.zip`，解压到一个**不会移动**的地方
   - Mac 建议：`文稿 / AIforBusiness-Chat-Assistant`
   - Windows 建议：`文件（Documents）\AIforBusiness-Chat-Assistant`，也就是 `C:\Users\你的名字\Documents\AIforBusiness-Chat-Assistant`
   - **不要**解压到 `C:\` 底下、`C:\Users\Public`、Mac 的 `/Users/Shared` 或 U 盘：这些地方同一台电脑的其他用户也能改里面的程序
   - 先核对压缩档没被改过：老师会给你一组 SHA-256 码（档名旁边的 `SHA256SUMS.txt`）。Mac 终端机 `shasum -a 256 档名.zip`；Windows PowerShell `Get-FileHash 档名.zip`，结果要一模一样

解压后会看到：`extension` 文件夹、`server` 文件夹、`aiforbusiness-chat-assistant.mcpb`、这份说明。

## 第 1 步：装 Chrome 插件（约 3 分钟）

1. Chrome 地址栏输入 `chrome://extensions`，按 Enter
2. 打开右上角 **「开发人员模式」**
3. 按左上角 **「载入未封装项目」**，选解压出来的 **`extension`** 文件夹
4. 出现 **「AI for Business Chat Assistant」**（黄色「AI+」图示）就成功了
5. 按 Chrome 右上角拼图图示，把它**钉选**到工具列，以后一按就开

> 「错误」按钮出现「连线失败」不用理：那是插件在找 AI 的本机程序，AI 还没开时就会这样。

> **插件画面默认是英文。** 要换中文：WhatsApp 网页左边的黄色「AI+」→ **Settings** → **Language** → **中文**。这份说明里写的按钮名称是中文版的。

## 第 2 步：确认插件读得到 WhatsApp

1. 确认 web.whatsapp.com 分页开着、已登入
2. 按工具列上的插件图示
3. 应该看到「等我回 / AI 草稿 / 全部」三页和你的对话。右上角会是红色「没连上 AI」——正常，下一步接 AI

## 第 3 步：接上 AI（选一个）

### 3A. Claude 桌面版（推荐，最简单）

1. 双击 **`aiforbusiness-chat-assistant.mcpb`**
2. Claude 桌面版会跳出安装画面，按 **「安装」**（提醒「不是官方审核」时：只有这个文件是老师给你、SHA-256 码也对得上，才选继续）
3. 完成。不用另外装任何东西

### 3B. ChatGPT 桌面版（Codex / Work）

装成 ChatGPT 的**插件（plugin）**，不用自己填路径。要先装 **Node.js**：到 nodejs.org 下载 **LTS** 版安装（一路按「下一步」）。

1. 打开 ChatGPT 桌面版，切到 **Codex**，开一个新对话
2. 把下面这段整段贴进去，把 `<文件夹>` 换成你解压的位置（例如 Mac：`~/Documents/AIforBusiness-Chat-Assistant`；Windows：`C:\Users\你的名字\Documents\AIforBusiness-Chat-Assistant`）：

```text
请帮我安装 AI for Business Chat Assistant 插件。插件市场就在这个文件夹：<文件夹>
1. 先检查 node -v（要 18 以上）。没有就停下来，告诉我去 nodejs.org 装 LTS 版。
2. 执行：codex plugin marketplace add "<文件夹>"
3. 执行：codex plugin add aiforbusiness-chat-assistant@aiforbusiness
4. 执行：codex plugin list，确认 aiforbusiness-chat-assistant@aiforbusiness 显示 installed, enabled。
5. 告诉我：要完全关掉 ChatGPT 再打开，然后在新的 Codex 对话问「WhatsApp 状态」拿配对码。
不要改这个文件夹里的任何文件，不要安装其他套件。
```

3. 照它说的，**完全关掉 ChatGPT 再打开**
4. 之后在 ChatGPT 的 **Plugins（插件）** 页也会看到「AI for Business Chat Assistant」，可以在那里开关或移除

> 这是「只限桌面版」的插件：要在 ChatGPT **桌面版**的 **Codex** 或 **Work** 里用。网页版和手机版连不到你电脑里的程序。
> 会用终端机的人可以自己打上面第 2、3 步的指令。

### 3C. Claude Code

装成 **Claude Code 插件**。先装 Node.js（同 3B），然后在 Claude Code 里打：

```
/plugin marketplace add <文件夹>
/plugin install aiforbusiness-chat-assistant@aiforbusiness
```

装好后重新开 Claude Code。`/plugin` 可以看到、关掉或移除它。

## 第 4 步：配对（只做一次，约 1 分钟）

1. 在 AI 里开新对话，问：**「WhatsApp 状态」**
2. AI 会回你一个 **6 位数配对码**（例如 `123 456`，中间的空格可打可不打。这个码只在你的电脑里用，不会从网络传出去；**3 分钟内有效**，过期了再问一次「WhatsApp 状态」拿新的）
3. 按 Chrome 工具列的插件图示 → 在黄色「要配对」框输入配对码 → 按 **「配对」**
4. 右上角变成绿色 **「已连上 AI」** 就好了

以后打开 AI 会自动连上，不用再配对。

## 怎么用

在 AI 里直接问，不用特别说「WhatsApp」，例如：

- 「谁在等我回？」（AI 会顺便帮清楚的几个起草回复）
- 「把 XX 群这星期讲的事整理成 3 点」
- 「回复一下 XX，说明天可以」

AI 会自己去读对话、把回复存成草稿，不会先问你要不要起草；草稿**不会发出去**。需要价钱、日期这类它不知道的资料时，它会先问你。

**起草后：**

1. 仪表板「概览」最上面的新草稿按 **「打开」**，或插件图示 → **「AI 草稿」** 页（新的是淡黄底）→ **「打开对话」**（会标已读，对方会看到蓝勾）
2. WhatsApp 输入框上方会出现 **AI 草稿预览卡**
3. 按 **「填入输入框」**，看一下、改一改，**再自己按发送**
4. 不想用就按「不用了」
5. 要整条删掉：插件弹窗「AI 草稿」页或仪表板，按 **「删除」**，再按一次确认

草稿卡浮在输入框上方时，对话会自动往上留出空位，不会盖住最新的信息。

草稿只存在你的电脑，保留 90 天；「AI 草稿」页底部可以一键清空。

### 仪表板

WhatsApp 网页左边侧栏（聊天、动态那一排）在 Meta AI 下面多了一个**黄色「AI+」图示**，按下去会打开整页仪表板（插件弹窗里的柱状图按钮也会切到 WhatsApp、打开同一个仪表板）：

- **概览：** 最上面是**新的 AI 草稿**（淡黄底、「新」字，按「打开」直接去那个对话）；下面是谁在等你回、未读、资料安全示意图（资料只在你的电脑）、每天收发多少、别人通常几点找你
- **AI 活动纪录：** Claude / ChatGPT 每次读了什么、什么时候（上次同步时间、上一个请求）
- **草稿 vs 实际：** AI 写的草稿旁边是你之后真的发出的信息
- **导出：** 「对话时间线」按时间排好每一条信息（可选择要不要放入 AI 草稿），还有草稿、活动纪录等 CSV / JSON，存到「下载」文件夹

按右上角 ✕ 或 Esc 回到 WhatsApp。

## 常见问题

| 看到 | 怎么办 |
|---|---|
| 黄色「还没连上 AI」 | 还没配对过：照第 3、4 步接上 AI、输入配对码（仪表板最上面也能输入） |
| 红色「AI 没开」 | 之前配对过，只是 Claude / ChatGPT 现在没开。打开就会自动连上，不用再配对 |
| 仪表板写「插件刚更新过，这一页跟插件断线了」 | 重新整理 WhatsApp 页面（⌘R / Ctrl+R） |
| 有人一直出现在「等你回」，但其实不用回 | 按旁边的「不用回」，或在 WhatsApp 打开那个对话、按标题下方的「不用回」。对方再传新信息才会回来；AI 问「谁在等我回」也不会列出他 |
| 「等你回」堆了很多很旧的对话 | 仪表板 → 设定 → 自动「不用回」选 7 / 14 / 30 天，超过的自动不算；对方再传信息就会回来 |
| 黄色「要配对」 | 照第 4 步输入配对码 |
| AI 说「WhatsApp Web 没开」 | 在 Chrome 打开 web.whatsapp.com 并登入 |
| AI 说「这个对话电脑里只存了这么多条」 | 正常：WhatsApp Web 只在电脑里存最近的信息。在手机上滑过的旧信息电脑里没有 |
| 有几个对话「判断不了」有没有在等你回 | 那些对话电脑里一条信息都没存，不乱猜 |
| 配对码错太多次 | 完全关掉 AI 软件再打开，重新问「WhatsApp 状态」拿新码 |
| Windows 跳出防火墙提示 | 程序只用本机 127.0.0.1，选「取消」也能用 |
| AI 说「all 10 local ports are in use」/ 本机程序没启动 | 旧版同时开太多 AI 对话会这样。装 0.7.0 后，把 Claude 和 ChatGPT 完全退出再打开一次（Mac 按 ⌘Q），之后开多少个对话都可以 |
| 移动了解压的文件夹 | Chrome 插件要重新「载入未封装项目」；ChatGPT / Claude Code 的插件不受影响（装的时候已经复制一份），要更新新版时再装一次 |

## 从旧名字「WhatsApp Assistant」升级

0.12.0 起改名叫 **AI for Business Chat Assistant**，功能一样。旧版的 AI 插件要先移除，不然会有两份（插件代号 `whatsapp-assistant` 或 `chat-assistant` 都算旧版）：

1. Claude 桌面版：设定 → 扩展 → 移除「AI for Business – WhatsApp Assistant」，再双击新的 `aiforbusiness-chat-assistant.mcpb`
2. ChatGPT / Codex：`codex plugin remove whatsapp-assistant@aiforbusiness`（或 `chat-assistant@aiforbusiness`），再照第 3B 步装 `aiforbusiness-chat-assistant@aiforbusiness`
3. Claude Code：`/plugin uninstall whatsapp-assistant@aiforbusiness`（或 `chat-assistant@aiforbusiness`），再照第 3C 步装新的
4. Chrome 插件：照第 1 步重新「载入」新的 `extension` 文件夹就好；配对不用重做

## 怎么移除

1. `chrome://extensions` → 移除插件
2. Claude 桌面版：设定 → 扩展 → 移除；ChatGPT：Plugins 页 → 移除（或 `codex plugin remove aiforbusiness-chat-assistant@aiforbusiness`）；Claude Code：`/plugin uninstall aiforbusiness-chat-assistant@aiforbusiness`
3. 删除配对密钥文件夹：Mac `~/.whatsapp-readonly-mcp`；Windows `C:\Users\你的名字\.whatsapp-readonly-mcp`
4. 删除解压出来的文件夹（里面是程序，留着没用）
